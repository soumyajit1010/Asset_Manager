# HR & Asset Management System

**A stunning, full-featured, console-based Enterprise Java Application** for managing company assets and employees with a beautiful, colorful, and professional user interface.

Fully built with **pure Java** — no external dependencies, zero crashes, perfect OOP design.

## Features

### Asset Management
- Add, View, Update, Delete assets
- Strict validation: `DSK-123456H`, `LTP-000001L`, `IPH-987654H`
- Expiry date validation (`YYYY-MMM-DD`)
- Case-insensitive ID search
- In-memory database with fast lookup

### Employee & HR Management
- Support for **Permanent** and **Contract** employees
- Automatic salary calculation
- **Only Permanent employees** can be assigned assets
- One asset → one employee (no duplicates)
- View employee + assigned assets in a beautiful format

### User Experience
- Gorgeous colorful terminal UI with banners, boxes, and emojis
- Smooth navigation between modules
- Professional menus and error handling
- Zero crashes — bulletproof `Scanner` management
